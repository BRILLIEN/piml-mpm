# 执行计划（依据 docs/task_original.docx）

## 1. 任务目标（我的理解）
基于问题无关机器学习（PIML）的 MPM 高效计算研究，**显式、隐式两条独立路线**：
- 各自先建立可信、高效的单线程基准并做**计时分解**，定位真实瓶颈；
- 构建**非学习**力学加速机制（显式：局部动力学降阶/稀疏积分/超降阶/可复用局部动力学算子等；隐式：连续多尺度空间、局部凝聚、积分超降阶、预条件），区分"降自由度 / 降算子求值成本 / 减迭代次数"三种机制的贡献；
- 在非学习方案之上引入 PIML（学习由局部材料+必要状态决定、跨工况复用的局部量），须给出**可测量的额外净收益**；
- 解决 cell-crossing：连续性（单位分解、刚体运动、一次场再现、人工界面连续性）+ 跨格时程/速度梯度/应力/能量/网格偏移对比 + 成本分析；
- 加速论证三层面：力学原理、复杂度/Amdahl 上限、实际单线程计时；阶段目标：百万级细尺度自由度下主要模块 20–40×，探索 ~100×（须真实验证，不预设）。

## 2. 约束
- 单线程 CPU，禁止 GPU/多线程/框架优势；无 MATLAB → Python(numpy/scipy)，只用 MATLAB 有直接对应的运算（稀疏矩阵、`spsolve`/PCG、向量化）。
- 主程序结构：基础条件设置 → 算例设置 → 求解过程 → 数据整理与比较；中文注释；显式/隐式模块独立；绘图比较独立可选；ML 全部放 `ml/`。
- 未经授权：不 push / merge / 部署；只在本容器内本地 git 提交。

## 4. 验收标准
- 基准：能量守恒/收敛性/与解析或参考解对比误差在预定阈值内；计时分解完整。
- 加速：同设置成本比较 + 统一误差容限下等精度比较；完整计入全部开销；训练/数据生成单列。
- PIML：相对非学习加速方案的增量加速比 > 1 且精度不劣于阈值；跨工况独立测试通过。
- cell-crossing：形函数 C¹ 连续性数值检验、网格偏移对比、能量曲线。
