# 修订执行计划 v2（2026-11-23）—— 隐式路线优先，按目标模块评价加速

## 1. 修订要点（依据用户 2026-11-23 补充说明）
1. **加速目标针对核心计算模块**：20–40×（挑战目标）、约 100×（探索）指"非学习力学策略对目标模块"的加速，规模为**百万级细尺度参考自由度**；不要求完整 MPM 分析达到该倍数。
2. **三个加速比严格区分并分别报告**：
   * S_NL = 原始 MPM 目标模块耗时 / 非学习策略目标模块耗时；
   * S_ML = 非学习策略目标模块耗时 / PIML 策略目标模块耗时（同一目标模块、统一精度要求下的额外净加速）；
   * S_tot = 原始 MPM 完整分析耗时 / PIML-MPM 完整分析耗时（受 Amdahl 定律约束）。
   每次实验同时记录目标模块、其他模块、完整分析三层耗时，并给出复杂度分析与 Amdahl 理论上限。
3. **研究顺序**：先集中完成隐式积分 MPM；在隐式策略于力学理论、精度、稳定性、问题无关性、实际加速上充分验证后，回到显式路线（保留已有成果，不从零开始）。
4. 显式路线的认识修正：背景网格节点更新（本工作实测 ≈4–5%）与粒子—网格传递、形函数/梯度、内力计算须分开统计；后者（≈90%）才是显式的主要瓶颈。

## 3. 已识别的问题（进入 v2 前必须处理）
| 编号 | 问题 | 影响 | 处理 |
|---|---|---|---|
| P1 | 原始基准 pattern 用 np.unique 排序（占原始 M 的 23–35%），不够高效 | 高估加速比，不公平 | 改为结构化网格固定模板（节点 ±2 邻域，5×5 模板）直接计算 CSR 位置；所有方法共用 |
| P2 | 有限转动闭锁：步内有限转动在非均质单元产生虚假应变 | 载荷步必须细（10 步误差 23%） | 共旋（co-rotational）局部框架构造/使用基；目标：10–20 步误差 ≤2% |
| P3 | 投影 ΦᵀKΦ 先组装细尺度 K（每粒子 324 项）再三重积 | PIML 后占 41% | 粗单元级积分压缩：每粗单元用少量积分点（ECSW 型 NNLS 或基于材料图像的 Gauss 压缩）直接组装粗切线，避免细尺度 K |
| P4 | 局部算子（basis）每载荷步全量重建 | 非学习方案占 56% | 增量更新：只重建材料分布变化超过阈值的粗单元（粒子迁移检测） |
| P5 | 精度只与同离散细尺度解比较，2–4% 误差偏大 | 统一精度要求 | 精度阈值事先规定：自由端位移 ≤1%、反力 ≤1%、应力场 L2 ≤3%（待确认） |
| P6 | 百万级细尺度完整参考解代价（外推 ≈63 h/40 步） | 无法在一夜完成完整对照 | 百万级做"目标模块单次 Newton 迭代计时"+短载荷历程；完整精度对照在 ≤2.6×10⁵ 自由度完成并检查误差随规模的趋势 |
