# 基于问题无关机器学习的 MPM 高效计算研究 —— 阶段报告（2026-11-09/10 夜间执行）

> 本报告只陈述已实际运行并可复现的结果；所有计时均为单线程（`tools/guard.sh` 强制 `OMP/OPENBLAS_NUM_THREADS=1`），
> 同一表格内的方法在同一机器、同一实现风格（Python + numpy/scipy，只用 MATLAB 有直接对应的运算）下比较。
> 后台并行运行的其他作业可能对绝对时间有轻微影响，相对比较均在同一批次内完成。复现命令见第 7 节。

## 1. 结论摘要

| 路线 | 已建立 | 关键结论（真实数据） |
|---|---|---|
| 显式 | 非均质悬臂梁大幅振动基准（USL/MUSL，二次 B 样条） | 计时分解：形函数 30%、P2G 25–30%、G2P 31–35%、本构 5%、网格 5% ⇒ **Amdahl：仅减网格自由度 ≤5% 收益**，必须减少粒子运算与时间步数 |
| 显式 | 多尺度粗运动学 + 区间冻结映射（TL 子步）+ 状态相关基重建 | 临界步随粗化比增大（n=8：≈5.8×，经小切割外推）；**MsFEM 型光滑骨架在无尺度分离的非均质材料中系统性偏刚（频率误差 10–20%）**；经 Guyan 上界实验定位后提出**边自适应（两单元过采样）基**，频率误差降到 3–5%，动力学自由端误差 17–18% → 5.5% |
| 显式 + PIML | 学习"两单元材料图像 → 骨架条带值" | 精确边问题占基重建 ~90%、占总时间 ~65%（n=8,K=50）；网络推理 ≈0.75 MFlop/边 vs 精确 6.7 ms/边 → 见 §4.4（ML 增量净收益实测） |
| 隐式 | UL 准静态 Newton（一致切线：材料+几何），载荷步内冻结映射 | 直接法（SuperLU, MMD）在 2D、≤~2×10⁴ 自由度时最快；低填充 ILU-PCG 不收敛；两级 PCG（多尺度粗空间）对比度 1000 时较双线性粗空间减少 21% 迭代，但仍慢于直接法 |
| 隐式 + PIML | 学习多尺度基 Φ_I 用作粗空间 | 预条件质量保持（PCG 次数 +1.2%），**但无时间净收益**：2D 局部凝聚问题很小，精确求解 0.04–0.5 MFlop/单元 < 网络 0.28–1.38 MFlop/单元 |
| cell-crossing | 机理检验 + 动力学批量 | 二次 B 样条使跨格虚假内力降低 6–16×，但随机粒子分布下粒子积分误差仍在（0.056–0.24 σh）；线性形函数 USL 在 h=0.01 发散 |

**诚实评估**：在本夜可用时间内，阶段性目标（百万级细尺度自由度下主要模块 20–40×）**未达到**。已得到的是：
(1) 两条路线可信基准与计时分解；(2) 一个经机理诊断改进、具备严格单位分解/刚体再现的多尺度显式加速方案（h=0.005 时非学习 3.69×/1.8% 误差，PIML 后 7.44×/2.3%）；
(3) 明确找到 PIML 能产生真实净收益的局部对象（边自适应条带），以及不能产生净收益的对象（2D 下直接学习 Φ）。

## 2. 基准问题与计时分解

### 2.2 隐式基准（implicit/main_implicit.py）
同一几何与材料，体力 20 m/s² 分 10 个载荷步施加（自由端挠度 ≈0.33–0.35 L），Newton 收敛 |R|/|f| < 1e-8。
关键稳健性措施：细尺度"小支撑节点"外推约束（质量 < 5% 满节点质量的节点由最近 3×3 好节点二次 Lagrange 外推，
扩展 B 样条思想），消除了重映射后 Newton 振荡（无此措施时第 2 载荷步不收敛）；对解的影响 ≈0.1%。
h=0.01（≈4.3k 自由度）直接法：9.6 s，45 次 Newton；pattern 27%、切线 25%、线性求解 45%。h=0.005（≈18k 自由度）：101 s。

## 3. cell-crossing 研究（explicit/cellcross_test.py、test_shape.py）
* 形函数检验：二次 B 样条单位分解、一次场再现、梯度和、梯度一次再现均 ~1e-15；跨网格线 **梯度跳变 2.6e-8（C1）**，线性形函数 1.34（C0）。
* 均匀应力块体（精确内部节点内力为 0）：

| 粒子状态 | linear ppc2 | linear ppc4 | qbspline ppc2 | qbspline ppc4 |
|---|---|---|---|---|
| 规则格点整体平移 δ∈[0,h) | 2e-16 | 3e-16 | 1e-15 | 1e-15 |
| 7% 非均匀拉伸 | 0.56 | 0.28 | 0.035 | 0.019 |
| 随机扰动 ±0.25d | 0.85 | 0.37 | 0.24 | 0.056 |

  ⇒ 跨格误差的根源是"梯度不连续 × 非均匀粒子分布"；C1 形函数使其降低 6–16 倍，但**粒子积分误差并未消失**（需更多粒子或积分修正）。
* 多尺度基在粗化后**不重新引入梯度跳变**：粒子层面插值仍为细尺度 C1 二次 B 样条，粗基只决定细节点值（单值）；
  骨架取粗二次 B 样条（C1）值；基的局部刚度用材料图像 + Gauss 积分（与粒子分布无关），均质区一次场精确再现（1e-15），
  而直接用粒子积分时为 2.4e-3（粒子积分误差进入基）。
* 动力学批量（explicit/analyze_cc.py；h=0.01，t∈[0,0.8] s，≈1 个周期，3 种背景网格偏移 (0,0)/(0.5,0.5)/(0.25,0.75)h）：

| 格式 / 形函数 | 稳定性 | 能量漂移 ΔE/Es,max | 根部 σxx 高频噪声 | 网格偏移敏感度 | 每步耗时 |
|---|---|---|---|---|---|
| USL / 线性 | **全部发散**（J≤0，step 2–625，小质量节点） | — | — | — | — |
| MUSL / 线性 | 稳定 | −0.52 ~ −0.61（强耗散） | 1.8–2.6e-2 | 7.0% | 4.9–6.2 ms |
| USL / 二次B样条 | 稳定 | −0.026 ~ −0.027 | 1.3–1.7e-5 | 2.7%（2 种偏移） | 7.6 ms |

  ⇒ C1 形函数使虚假应力振荡降低约 3 个数量级、能量漂移降低 20 倍以上，代价为支撑节点 4→9、每步耗时约 +50%。
  网格偏移敏感度未降到零：其中一部分来自固支节点列随网格偏移改变（边界条件离散差异），一部分为粒子积分误差；
  线性形函数 MUSL 的挠度明显偏大（−0.50 ~ −0.56 vs −0.44 ~ −0.46）。图：results/explicit/cc_analysis.png。

## 4. 显式路线：多尺度运动学加速

### 4.1 方法（explicit/mpm_explicit_ms.py，common/msbasis*.py）
* 粗运动学 v_h = Φ V；粗尺度方程由细尺度 Galerkin 投影得到：一致质量 Mc = ΦᵀMΦ（**不用静力凝聚的等效刚度替代惯性**；
  粗系统规模 ≈ 细节点数/n²，一次分解、每步回代）。
* 更新区间（K 步）内冻结粒子—网格映射，以区间起点构形为参考的完全拉格朗日内力 f = −Σ V⁰ P_rel ∇₀N（与基准相同本构与积分）；
  省去每步形函数求值、质量/动量 P2G、位置更新；区间末更新粒子并按新材料分布重建 Φ（状态相关局部算子）。
* 区间交界速度传递用 PIC（每区间一次）：实验表明 FLIP 0.99 在基切换时注入能量（基含负值，投影非能量有界）。
* 小切割粗自由度外推约束（Φ_eff = Φ C，C 为 Lagrange 外推，∑w=1）：精确保持单位分解与多项式再现，消除"质量极小而刚度有限"的自由度。

### 4.2 关键诊断（均为实测）
| 现象 | 证据 | 处理 |
|---|---|---|
| 行和集中质量在基含负值时失效 | 表面上方粗自由度 Mc ≈ 6e-9·max，出现 0.002 Hz 伪模态 | 改一致质量 |
| 小切割自由度限制临界步 | 一致质量下 dt 放大仅 1.0–2.0× | 外推约束后 2.7×(n=4)/5.8×(n=8) |
| 非均质时粗空间偏刚 | 均质时频率误差 < 0.15%；非均质 10–20% | 见 4.3 |

### 4.3 精度瓶颈定位与边自适应基
全局 Guyan 静力凝聚上界实验（h=0.01，前 4 阶频率相对误差）：

| 约束集合 | n=4 | n=8 |
|---|---|---|
| 整个双线骨架强制为粗函数（MsFEM 型） | 11–16% | 9–14% |
| 仅粗节点处 2×2 角块强制 | 2.4–3.1% | 0.2–1.4% |

⇒ 误差来自"骨架被强制光滑"。**边自适应基**（common/msbasis_os.py）：每条骨架条带在共享它的两个粗单元构成的块上求局部问题，
单元内部再以角块+自适应条带为边界凝聚；协调、单位分解与刚体转动 1e-11 精确。频率误差（无外推）：n=4 5.0–6.5%，n=8 2.8–4.2%
（原 MsFEM 型 12–17% / 10–16%）。

### 4.5 PIML 增量净收益（实测，results/explicit/t7*）
学习对象：两单元材料图像（n×2n 细区间 log 模量比）→ 骨架条带值（24 行 × 40 粗列）；PU/刚体由投影精确满足；
含固定节点的边回退精确求解。训练数据完全为合成随机图像对（问题无关），x/y 两向各一模型（256→256→256→960，0.75 MFlop/边）。

| 量 | 精确边问题 | PIML |
|---|---|---|
| 边问题（单线程） | 6.7 ms/边 | ≈0.15–0.2 ms/边（批量推理） |
| 基重建（h=0.01/0.005） | 0.36 / 0.77 s | 0.12 / 0.30 s |
| 前 4 阶频率误差（h=0.01 / 0.005） | 2.8–4.2% / 2.4–3.7% | 5.7–7.0% / 3.2–4.9% |
| 显式全程（n=8,K=50）总时间 | 34.0 s（2.37×） | 16.6 s（**4.86×**） |
| 其中基重建 | 21.7 s | 4.0 s |
| 自由端轨迹误差 | 5.45% | 7.4% |

* **ML 增量加速比（完整分析）= 34.0/16.6 = 2.05×**；基重建模块 5.4×。

* 离线成本（单列）：每向 2.2 万样本精确标签 ≈150 s + 训练 ≈60 s，合计 ≈7 min，一次性、与整体问题无关。
* 代价：网络误差使频率误差增加 1–3 个百分点。

### 4.8 第三机制：粒子积分聚合（免训练超降阶）
区间内运动学被限制在粗空间，故内力积分可在"同一细区间（或 a×a 区间块）内同一材料相"的粒子上合并：
合并点体积 = ΣV_p、位置 = 体积加权质心、F₀ = 体积加权平均、模量取该相；质量、区间末粒子位置/变形梯度仍对全体粒子精确更新（每区间一次）。
稳定性依据：合并点数 × 3 个应变分量 ≫ 粗自由度数，粗刚度保持满秩，不在粗空间引入沙漏模态。

| 方案（n=8，K=50，PIML c100） | 积分点/粒子 | h=0.01 加速 / 自由端误差 / 应变能误差 | h=0.005 加速 / 自由端误差 / 应变能误差 |
|---|---|---|---|
| 不聚合 | 1.00 | 5.98× / 6.8% / 7.0% | 7.44× / 2.3% / 2.8% |
| **agg=1（每区间每相一点）** | 0.28–0.31 | **8.52× / 6.2% / 4.5%** | **9.85× / 2.6% / 2.1%** |
| agg=2（2×2 区间块） | 0.10 | 8.77× / 3.0% / 13%（末时刻能量 +12%，欠积分迹象） | — |

h=0.005、agg=1 的时间构成：基重建 29%、区间质量/分解 13%、能量输出 12%、每步聚集/散射 23%、粗尺度 11% ——
各环节已较均衡，继续提速需同时优化区间成本（质量矩阵与基的增量更新、更长的安全区间）与每步成本。

### 4.9 复杂度与 Amdahl 分析（h=0.005 实测分解）
总加速比 S = (N_f·c_f) / (N_r·c_r + N_int·c_int + c_out)，其中
N_f/N_r = 临界步放大 = 4.46（粗运动学滤除细尺度高频；经小切割外推）；
c_f/c_r = 每步细尺度/约化粒子运算之比 = 40.2/14.8–15.8 ms ≈ **2.6–2.7**（省去形函数求值、质量/动量 P2G、位置更新，但内力的粒子聚集/散射仍为 O(N_p)）；
N_int·c_int = 区间重建（精确边：160 s，其中基 143 s；PIML：42 s，其中基 24 s）。

| 方案 | 实测 S | 区间成本→0 的上限 | 再去掉输出的上限 |
|---|---|---|---|
| 精确边 K=50 | 3.69 | 10.6 | 11.4 |
| PIML K=50 | 7.44 | 11.3 | 12.1 |

⇒ **当前机制的理论上限 ≈ 12×（= 4.46 × 2.7）**。PIML 已把可达比例从 32% 提到 62%。
要达到 20–40×，必须引入第三个机制——**减少每步参与内力积分的粒子数**（粒子积分超降阶 / ECSW，或可复用的局部非线性内力算子），
例如每步粒子运算再降 5× 则上限 ≈ 4.46 × 13 ≈ 60×；且粗化比 n、问题规模增大时 N_f/N_r 继续增大（n=8 理论 ≈ n·√(m_l/m_c)）。
这一判断与"自由度削减率不等于加速比"一致：细节点数削减 ≈64×（n=8），但实际总加速只有 3.7–7.4×。

⇒ 隐式 ML 增量 1.68×；下一瓶颈为 ΦᵀKΦ 投影（先组装细尺度 K 再三重积），已实现在聚合点上直接组装粗切线 G_qᵀ C G_q（G_q = ∇N_q Φ，选项 `_dc`）：结果与三重积一致（差 3e-16），
但更慢（h=0.01、40 步：22.6 s vs 13.4 s）——粗梯度每行 ≈72 个非零，8 个稀疏乘积的代价超过"细尺度组装 + 一次三重积"。负结果，保留原实现。

诊断：线性（微小载荷）时约化解与细尺度之比 0.90（基本身偏刚 10%，与频率误差一致）；载荷步增大时误差显著增大（10 步 22.8% → 40 步 5.4%）。
机理：基在步初构形构造，步内采用完全拉格朗日描述；基精确再现常数与**无穷小**刚体转动，但在非均质单元内不再现一般线性场，
而有限转动的位移场 (R−I)X 含对称部分 (cosθ−1)I，于是步内有限转动产生虚假应变（"有限转动闭锁"）。
对策（待做）：共旋（co-rotational）局部框架下的基，或在步内按转角自适应细分载荷步。
机制分解（h=0.01，40 步）：M2 消除了 45% 的线性求解；M3 把 pattern+切线由 52% 降到 19%；新增基构造 58% 与投影 20%——PIML 针对前者。

机制区分：两级预条件属于"减少迭代次数"（细尺度解精确，与直接法差 1e-16）；
PIML-Φ 粗空间：PCG 次数 2368 vs 精确 2339，基构造时间 3.83 s vs 3.35 s ⇒ **无净收益**。
结论：二维、≤2×10⁴ 自由度时稀疏直接法最优；两级 PCG 迭代数随 h、n 增长（52→300 次/求解），需更强平滑器/谱粗空间（GenEO 型）
才能在更大规模（尤其三维）胜出 —— 谱粗空间的局部特征值问题昂贵，是 PIML 更有希望产生净收益的隐式对象。
